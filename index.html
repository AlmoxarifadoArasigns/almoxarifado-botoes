📘 COMO PROGRAMAR AS TAGS

Grave cada tag como texto NDEF usando um app como NFC Tools. O conteúdo precisa seguir exatamente um destes formatos:

FUNC|RAMALHO
ITEM|FERRAMENTAS|TRENA|TR-001

Use o nome do funcionário da lista do sistema. Para ferramenta, use categoria, nome e um código único da etiqueta (ex.: TR-001). Cada ferramenta física deve ter um código diferente, mesmo quando forem do mesmo modelo.
